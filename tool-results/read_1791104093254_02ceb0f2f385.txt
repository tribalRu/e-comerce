    38→    38→### API contracts (все — route handlers, JSON)
    39→    39→- `GET /api/categories` → `[{ id, slug, name, sort, count }]` (count = число товаров), по sort asc
    40→    40→- `GET /api/products?category=<slug>&search=<q>&sort=popular|price_asc|price_desc|rating|new&featured=1&limit=N`
    41→    41→  → `Product[]` c вложенным `category: { id, slug, name }`.
    42→    42→  Сортировки: popular → reviewsCount desc, rating desc; rating → rating desc, reviewsCount desc;
    43→    43→  new → createdAt desc. search — фильтр по name+description без учёта регистра (SQLite `contains`
    44→    44→  чувствителен к регистру → фильтровать в JS).
    45→    45→- `GET /api/products/[id]` → `Product` | 404 `{ error }`
    46→    46→- Cart cookie: `km_cart` (uuid, httpOnly, sameSite=lax, path=/, maxAge 30 дней).
    47→    47→  Состояние корзины (возвращают все cart-эндпоинты):
    48→    48→  `{ cartId: string|null, items: [{ id, quantity, product: Product }], count, subtotal }`
    49→    49→  (count = сумма количеств, subtotal = сумма price*quantity; items по createdAt asc)
    50→    50→- `GET /api/cart` → состояние (без cookie → `{ cartId:null, items:[], count:0, subtotal:0 }`)
    51→    51→- `POST /api/cart` body `{ productId: number, quantity?: number>=1 }` → создаёт cookie при
    52→    52→  отсутствии, upsert CartItem (инкремент), возвращает состояние
    53→    53→- `PATCH /api/cart/[itemId]` body `{ quantity }` → quantity<=0 удаляет; проверять, что item
    54→    54→  принадлежит текущей корзине (иначе 404). Возвращает состояние
    55→    55→- `DELETE /api/cart/[itemId]` → удаляет item (проверка владения), возвращает состояние
    56→    56→- `DELETE /api/cart` → очищает корзину
    57→    57→- `POST /api/orders` body `{ customerName, phone, email?, address, delivery:'pickup'|'courier', payment:'card'|'cash', comment? }`
    58→    58→  → создаёт Order (number = `КМ-<6 случайных цифр>`, total = subtotal, снапшот items в OrderItem),
    59→    59→  очищает корзину, `201 { ok:true, order:{ id, number, total, itemsCount } }`.
    60→    60→  Валидация: имя ≥ 2 симв.; телефон ≥ 7 цифр; при delivery=courier адрес ≥ 5 симв.; иначе 400 `{ error }`
    61→    61→- Ошибки: `{ error: string }` + корректный HTTP-код; try/catch → 500.
    62→    62→- Next 16: `params` в dynamic routes — Promise (await); `cookies()` из next/headers — await;
    63→    63→  в route handlers cookie ставить можно.
